# 🚀 Srijan Paul — Data Analyst & ML Developer Portfolio

A high-performance, interactive portfolio showcasing data analytics, machine learning predictive modeling, statistical analysis, and interactive Power BI dashboards. Built with a dark/light glassmorphic UI, GSAP animations, smooth scrolling, and FormSubmit AJAX email integration.

🔗 **GitHub Repository:** [https://github.com/Srijan4920/PORTFOLIO](https://github.com/Srijan4920/PORTFOLIO)

---

## 💎 Key Features

### 1. 🧭 Recruiter Command Palette (`Ctrl+K` / `Cmd+K` or `Alt+1`–`6`)
Recruiters and hiring managers can access a modern navigation overlay by pressing `Ctrl+K` or `Cmd+K`. The command palette supports keyboard-friendly section jumping, direct project links, theme switching, and quick shortcuts.

### 2. 🤖 Predictive ML & BI Showcase
Features interactive case studies for end-to-end data analytics and machine learning applications:
* **MediPredict**: Multi-task hospital dataset predictor (logistic regression, decision trees, KNN, majority voting) with Streamlit UI & SciPy statistical testing (ANOVA, Kruskal-Wallis, Chi-Square).
* **SmartExp AI**: Financial expense tracker with linear regression 30-day spending forecasting & Cloud Firestore storage.
* **HR Analytics Dashboard**: Power BI executive workforce performance and attrition dashboard with DAX KPIs.
* **Credit Risk Modelling**: Scikit-learn loan default classifier evaluated via ROC-AUC metrics.
* **Fake News Detection**: Passive-Aggressive classifier with TF-IDF vectorization.

### 3. 📬 Asynchronous Contact Form (FormSubmit AJAX)
Integrated with FormSubmit's REST API for instant, zero-reload messaging directly to `srijanpaul6@gmail.com` with inline loading spinner feedback, success banners, and honeypot (`_honey`) bot protection.

### 4. 💼 Bento Grid & Smooth Scroll
Utilizes a modular bento grid for education, internship timelines, location widgets, live clocks, and certification spotlights. Integrated with **Lenis** for smooth scrolling and **GSAP** for staggered entrance animations.

## 🛠️ Tech Stack & Architecture

* **Analytics & ML**: Python · Pandas · NumPy · Scikit-learn · SciPy · Seaborn · Streamlit
* **Business Intelligence**: Power BI (DAX, Power Query) · Tableau · Excel
* **Frontend**: Vanilla HTML5 · CSS3 (Custom Properties & Glassmorphism) · ES6+ JavaScript
* **Animation & Motion**: GSAP (GreenSock) · ScrollTrigger · Lenis Smooth Scroll
* **Services**: FormSubmit AJAX API · Lucide Icons · GitHub Actions

## 💻 Setup & Local Development

Run the portfolio locally in seconds:

```bash
# 1. Clone the repository
git clone https://github.com/Srijan4920/PORTFOLIO.git
cd PORTFOLIO

# 2. Spin up a local development server
python -m http.server 8000
```

Once running, navigate to `http://localhost:8000` in your web browser.
